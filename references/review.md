# 出图审核

先看结果再写结论。不得从提示词、生成状态或文件名推断视觉通过。自审标记 `lead_review`；只有实际独立评审才标记 `independent_review`。

## 生成前

确认身份图已查看且会传给工具；参考图角色与编号分明；身份锚点有证据；不复制不可见花纹；实际提示词无空变量；用户约束未被默认覆盖。

## 硬门槛

| 项目 | 通过标准 | 失败/未知例子 |
|---|---|---|
| 可用性 | 可打开，像素宽高相等，背景不透明 | 无法查看、非方形、透明 |
| 身份 | 物种、脸型/吻部、毛色分区、独特标记一致 | 狗变猫、黑白变橘色、长吻变短、串宠 |
| 姿态 | 头颈摆正、双眼连线接近水平，轻度 3/4 有透视差异 | 源图侧倒未纠正、仍歪头、正脸、纯侧脸 |
| 帽子 | 正确主题、戴在头上、脸部露出 | 道具浮空、遮眼、主题错误 |
| 构图 | 头帽居中、关键装饰完整、脸够大 | 切兔耳、只居中身体、脸太小 |
| 背景 | 单一底色且有细密低对比毛毡纤维，无场景、装饰图案、明显渐变和暗角 | 光滑数字色块、彩色杂斑、粗纹抢主体、影棚或布景 |
| 完整性 | 无多宠、融合器官、乱码、水印和文字 | 第三只真实眼睛、复制原账号 |
| 卡通基础 | 想象去掉纤维后仍是二维卡通/绘本角色，身份锚点清楚 | 写实照片只套绒毛滤镜、摄影级玻璃眼和鼻纹、通用玩偶脸 |

宽高、文件和 alpha 可查元数据；身份、角度、帽子、材质必须看图。纯色毛毡背景允许纤维造成的同色细微明暗变化，不要求逐像素同一 RGB；细毛抗锯齿边缘也不是缺陷。背景必须看得到纤维质感，同时在小头像尺寸仍读作一种底色。

任何硬门槛 Fail 都不能靠美感分抵消。真实定制中身份来源不够或图不可查看时记 Unknown/Blocked，不编相似度百分比。`style_demo_only` 的真实宠物身份项记 N/A，改查示例角色与演示简报一致性；其余门槛照常。该模式通过仅代表风格演示通过。

## 质感审美

每项用 0 / 1 / 2 记录：0 明显偏离，1 基本达到但有可见缺陷，2 清楚达到。

1. 细纤维：细密绒感，不是噪点滤镜、粗线圈或全图糊化。
2. 材质区分：毛发有方向，帽子有毡面/拉绒和少量绣饰。
3. 造型表情：卡通化且保留个体，眼鼻嘴适度简化，不强行巨大黑眼、抹去虹膜色或统一幼猫脸。
4. 配色层次：毛色保真，脸/帽沿/底色均能分开；帽子与背景色相协调、有主次，不因历史示例固定棕底。主题适配耳型，视觉趣味不压过宠物脸。
5. 缩略图可读性：想象或实际看小头像，脸与帽主题仍清楚。

工作验收线：所有硬门槛通过、五项均不为 0、总分至少 8/10。这是设计约定，不是客观美学或身份准确率。

## 结论

- `pass`：硬门槛全通过且质感达线，交付。
- `targeted_fix`：身份和构图正确，局部问题，保持不变量修复。
- `regenerate`：身份、姿态、整体画风错，修提示词并从原片生成。
- `blocked`：真实定制缺身份图、结果无法查看或工具不可用，报告缺口。显式风格演示不因无真实照片被阻止，但绝不能据此验证真实身份还原。

修复遵循 SKILL.md 次数上限。每次保留前版，记录“发现什么 → 改哪项 → 实际结果”。补充提示词不代表问题已解决。
