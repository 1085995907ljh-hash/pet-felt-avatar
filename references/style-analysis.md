# 五张参考图的风格逆向

这是画面观察形成的重建方案，不是找回原作者实际提示词，也不能仅凭图片判断制作工艺。“羊毛毡”描述视觉效果。

## 固定风格语言

- 二维插画为基础，局部柔和浅浮雕；短而密的毛纤维沿脸颊、胸毛和帽沿生长。
- 边缘细小毛茸茸，内部毛色块和花纹清楚；不用全图模糊替代绒毛。
- 毛发有方向；帽子像压实羊毛毡、拉绒针织面料；帽上眼鼻像刺绣或毡片贴饰。
- 低反光、柔和体积、弱阴影，无强轮廓光、镜头景深和塑料高光。
- 先把身份锚点重绘成卡通/绘本角色：圆润形状、概括的毛发色块、简化眼鼻嘴、浅光影；再加纤维。帽子用大轮廓表达主题。不能只给写实脸加绒毛。
- 背景参考样图 1/5 的细密纤维起伏：单一底色的毛毡面，带低对比同色纤维与轻微明暗变化。纯色不是光滑无纹理；不加入多色斑块、图案、明显渐变、布料褶皱或场景。

## 构图目标（设计起点，非原图测量值）

头帽整体通常占画面宽度约 65–80%、高度约 70–85%；帽顶与两侧留约 6–10% 空间。视觉重心居中，底部少量胸毛自然出画。

遇到兔耳、龙角，先缩小整个头帽组合或缩短装饰，再减少胸部；不要把脸挤成小点。允许少量视线留白，不把头推到边缘。

## 容易跑偏的词

只写 `knitted plush toy`、`amigurumi`、`3D render` 易生成粗毛线玩偶、塑料眼或商品摄影；只写 `cute cartoon cat` 易抹掉个体。优先组合 `2D wool-felt illustration, dense fine wool fibers, softly fuzzy contours, brushed-knit bonnet, matte embroidered applique details`。

帽沿和系带可有细针目，宠物脸和背景不要铺满规则针脚。
